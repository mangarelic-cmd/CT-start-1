# Reproduce the public research demos

This directory closes **installation and entrypoint gaps for the available public code**. It does not replace missing original research artifacts or promote a partial rerun into a full validation.

## Quick start (Linux, Python 3.12)

From the repository root:

```sh
python3 -m venv reproducibility/.venv
reproducibility/.venv/bin/python -m pip install -r reproducibility/requirements.txt
# Install the Zstandard CLI with your system package manager if absent.
# Debian/Ubuntu: sudo apt-get install zstd
reproducibility/.venv/bin/python reproducibility/run.py
```

The runner verifies every vendored source hash, runs the published 100%-coherence Memory point (8,000,000 bytes → 88-byte capsule, excluding the shared decoder/runtime), all seven conventional codecs, the three supplied source-deletion/corruption checks, and Alignment's 16 new demos plus its 248,832-configuration finite audit. Expect roughly 25 seconds on a typical developer machine; timings vary.

For the complete **public generative benchmark** (10 coherence points and four scaling points):

```sh
reproducibility/.venv/bin/python reproducibility/run.py --full-memory
```

This takes several minutes. `--suite alignment` runs only the standard-library Alignment subset; `--suite memory` runs only Memory. `--output NEW_FILE.json` saves a new receipt and refuses to overwrite an existing one; its parent directory must already exist. Do not enable Python optimization (`-O` or `PYTHONOPTIMIZE`), since the upstream code uses assertions.

Memory code writes only in a disposable temporary copy. The source-deletion tests delete only generated temporary benchmark sources. Always use `run.py` as the entrypoint, not the vendored Alignment builder. The runner never executes the Alignment builder's historical `/mnt/data` cleanup. It evaluates the unchanged, hash-checked pure demo/audit sections and compares the fresh audit with the public receipt. Stored receipts alone are never counted as executed tests.

## Precisely what remains missing

- **Memory PASS016:** the original 60 core tests, 105 proof checks, 17 adversarial tests, and 11JSON corpus/codec behind 15,561,243 → 2,700,557 bytes remain unavailable here. These are not run or regenerated by this bundle
- **Alignment V6/AC73:** the four V6 JSON inputs and exact AC73 solver release remain unavailable. The 64 inherited V6 receipt rows are not 64 freshly executed tests; the full 80-demo build and AC73 audit are not claimed
- The finite, model-specific computational checks do not establish universal compression, general AI alignment, physical time-based storage, or external empirical validity

## Already complete public releases

The following releases already contain their runtime dependencies. A small downloader pins their archive SHA-256, validates archive member paths and size limits, and extracts into a **new** directory. It never executes downloaded code. Network access to Zenodo is needed only for this optional step. An already downloaded exact archive can be supplied with `--archive FILE.zip`.

### Temporal Causal Informatics PASS025

```sh
reproducibility/.venv/bin/python reproducibility/download_release.py temporal reproducibility/downloads/temporal
reproducibility/.venv/bin/python -m pytest -q reproducibility/downloads/temporal/tests
PYTHONPATH=reproducibility/downloads/temporal/src reproducibility/.venv/bin/python reproducibility/downloads/temporal/examples/example_pass010.py
PYTHONPATH=reproducibility/downloads/temporal/src reproducibility/.venv/bin/python reproducibility/downloads/temporal/benchmarks/pass025_residual_projection_benchmark.py
```

Expected suite: 386 tests; PASS025 benchmark: 10 checks and 33,867 relations. Runtime is standard-library Python; pytest is required for tests. Examples and older benchmarks need the explicit `PYTHONPATH` shown above. The packet's integrity gate covers the predicted endpoint; it is not complete authentication of an observed residual history.

### Hyperqubit II

```sh
reproducibility/.venv/bin/python reproducibility/download_release.py hyperqubit reproducibility/downloads/hyperqubit
reproducibility/.venv/bin/python reproducibility/downloads/hyperqubit/proofs/proof_suite_v5.py
```

Expected suite: 42 assertion groups; NumPy is its external runtime dependency. The script writes a new result receipt inside the downloaded working copy. This is a finite numerical prototype, not a quantum-hardware or general speedup validation.

### AC124 public instrumentation slice

Already available on [the pinned `ac124-public` commit](https://github.com/mangarelic-cmd/CT-start-1/tree/4bd11dcf7524a7453fdba9445c3a5a72647f9b2a/AC124). Its README intentionally describes a slice, not the whole solver. To run its four tests in a separate checkout:

```sh
git clone --branch ac124-public --single-branch https://github.com/mangarelic-cmd/CT-start-1.git /tmp/ct-ac124-checkout
cd /tmp/ct-ac124-checkout
git checkout 4bd11dcf7524a7453fdba9445c3a5a72647f9b2a
python -m pytest -q AC124/tests
```

Use a Python environment with the pinned pytest above. Choose a different new checkout directory if `/tmp/ct-ac124-checkout` already exists.

## Verification and provenance

```sh
python3 -m unittest discover -s reproducibility/tests -v
```

The dedicated `Public demo reproducibility` CI job runs these eight wrapper/safety tests and the complete public Memory benchmark plus scoped Alignment checks on Python 3.12. Optional large Zenodo downloads are not part of CI. See [VALIDATION.md](VALIDATION.md) for actual execution results and environment.

Upstream source and receipts are copied **byte-for-byte** from the two public Zenodo releases. [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json) records each file's source member, size, SHA-256 and parent archive hash. [PUBLIC_RELEASES.json](PUBLIC_RELEASES.json) pins the optional releases. [NOTICE.md](NOTICE.md) preserves author attribution and licenses. New wrappers provide portability and validation; the research implementation is not modified.
